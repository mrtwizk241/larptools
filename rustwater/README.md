# Rustwater Player Tools (unofficial)

The Rustwater part of larptools: a test builder for planning characters and the Soak and Damage
Calculator. No sign-in. Test builds are saved only in the visitor’s browser.

Made by a player, not by Rustwater LARP. Rustwater names, rules, and setting belong to
Rustwater LARP (see NOTICE at the repo root).

This folder is exported from a private repo, so changes made here are overwritten by the next
export. Open an issue instead.

## Commands (Node 24)

- `npm ci` then `npm run dev` (local test site), `npm run build` (writes `dist-public/`)
- `npm test`, `npm run test:e2e`, `npm run lint`, `npm run typecheck`, `npm run format:check`
