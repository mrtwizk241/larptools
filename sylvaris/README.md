# Sylvaris Player Tools (unofficial)

The Sylvaris part of larptools: a test builder for planning characters, the Life and Damage
Calculator, and the Rules Wiki. No sign-in. Test builds are saved only in the visitor’s
browser.

Made by a player, not by Sylvaris LARP or Sylvaris Games, LLC. Sylvaris names, rules, and
setting belong to their owners (see NOTICE at the repo root). The rules text here is a short
summary with page references, not the rulebook wording.

This folder is exported from a private repo, so changes made here are overwritten by the next
export. Open an issue instead.

## Commands (Node 24)

- `npm ci` then `npm run dev` (local test site), `npm run build` (writes `dist-public/`)
- `npm test`, `npm run test:e2e`, `npm run lint`, `npm run typecheck`, `npm run format:check`
- `npm run privacy-scan` checks this folder for private details before a commit.
